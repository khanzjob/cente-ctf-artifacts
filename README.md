# CenteHack CTF — Artifact Hosting

Download host for large binary challenge artifacts that don't fit in the
main challenge repository (which stays private and has no Git LFS
configured). This repo intentionally holds no challenge source, solutions,
or flags — only downloadable attachments, linked from the relevant
challenge's `challenge.yml`/`note.txt` in the main repo.

Check each release's description for which challenge it belongs to and
its SHA256 checksum before relying on the download.
